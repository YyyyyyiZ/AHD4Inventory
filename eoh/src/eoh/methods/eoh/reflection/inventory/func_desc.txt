The `compute_order_amount` function takes as input a `history_demand` list of demand quantities per period, a `history_inventory` list of ending inventory levels per period, a `history_lost` list of lost sales quantities per period, a `holding_cost` float as the holding cost per unit per period, and a `lost_sales_cost` float as the cost per unit of lost sales. And its returns the optimal order amount each period to minimize total costs (holding + lost sales). The return is a float.
