# DeepSeek 与低价开源 backbone：演化和优化对比

状态：实验流程与公共基线已准备完成；尚未发送新的模型请求。用户提到的 “Talk-2” 尚未对应到确定的模型 ID 和服务地址。

## 已完成的工作

- 沿用已有的 20 个易腐库存场景：寿命 `m ∈ {3,4,5,7,8}`，需求 CV `∈ {1.5,2}`，FIFO 份额 `f ∈ {0,0.5}`；交货期 2、平均需求 4、持有成本 0、缺货及过期单位成本均为 100。
- 结构搜索使用 `m=3,5,7` 的 12 个场景；`m=4,8` 的 8 个场景用于检验结构迁移。完整参数范围公开，迁移场景的表现不反馈给结构搜索。最终仍允许对每个实例单独调参。
- 使用新的需求样本；同一重复和阶段下，各 backbone 使用完全相同的样本。
- 5 种公共初始策略完成 3 次重复，共 15 个数值任务、180 个场景拟合，均成功。这是初始策略的数值优化，尚不是 DeepSeek 实验结果。
- 数值缓存与不使用缓存的结果已核对一致；优化会保留已拟合参数，数值搜索范围按参数尺度归一化，种群随参数数量增加。
- 已准备共享费用上限、断点记录与独立最终测试流程。

## 预定比较

用户指定的 DeepSeek 推理模型、一个较低价的开放权重模型，以及使用相同新流程的 Sol 对照。准确模型和推理设置将在接入信息明确后固定。

每个 backbone 做 3 次独立重复。每次先独立生成 4 个结构，再进行 12 次反馈演化。反馈包含策略代码、拟合后的参数、各场景成本、过期/缺货/订单量、数值工作量以及失败记录。参数数量不设上限。

每个训练候选有 512 次目标函数评估预算；晋级候选与最终重新拟合各有 1536 次预算。结构在独立验证样本上选择；全部模型的策略和参数冻结后，才统一生成最终测试结果。

报告将比较 20 场景平均相对成本、8 个迁移场景、各模型花费、无效候选比例和公共基线采用情况。优化器消融比较已选定结构的字面初值与优化后的参数，属于固定结构的条件消融，不能代表完全移除优化器后的完整搜索流程。

3 次生成重复只支持探索性判断；成本差距 2% 的筛查阈值不等于已证明非劣。没有完整重复时不剔除失败后只平均成功结果。
