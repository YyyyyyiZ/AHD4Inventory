# 规模扩展诊断：状态空间更难，不等于 AIPS 会胜出

**建议：如果只允许改变规模，优先把 `m=7/8, mean=4` 作为下一轮完整 family stress test。单独把均值提高到 20/40，虽然会让直接 DP 的状态数暴增，却主要改变库存计量尺度；粗粒度 DP 或归一化启发式可能仍然很有效。当前结果没有证明 AIPS 胜过 Baek。**

本轮固定 16 个场景，四种经典策略，没有调用 LLM，API 成本 $0，没有读取主实验最终测试 seed 17094001。

## 结构复杂度与实际观察

`L=2` 时，决策状态由 `m` 个库存年龄分量和 1 个在途分量组成。在统一 inventory-position cap `C` 下，完整非负整数状态集合的大小为 `comb(C+m+1,m+1)`。以下内存仅是一条 float64 value vector，尚未包括第二条 value vector、动作、状态索引和转移；也不是针对所有结构化算法的内存下界。

| 保质期 m | 均值 | 完整状态数范围 | 单条 value vector / GiB | 简单年龄策略对 CBS 的平均改进 | 四格改进范围 |
|---:|---:|---:|---:|---:|---:|
| 5 | 20 | 1,705,904,746–5,169,379,425 | 12.71–38.51 | 1.490% | 0.714%–2.360% |
| 5 | 40 | 98,619,368,491–296,672,379,003 | 734.77–2210.38 | 1.642% | 1.349%–2.182% |
| 7 | 4 | 30,260,340–76,904,685 | 0.23–0.57 | 1.759% | 0.927%–2.880% |
| 8 | 4 | 350,343,565–886,163,135 | 2.61–6.60 | 2.356% | 1.568%–2.974% |

四格是 `CV={1.5,2.0} × FIFO-share={0,0.5}`，全部报告。观察到的 0.7%–3.0% 左右差距，是已知简单年龄策略相对 CBS 的改进，**既不是全局最优性差距的上界，也不是 AIPS 对 Baek 的优势**。

增加保质期提高了状态维度，信息与动作仍是原模型的相同类型。增大均值且固定 CV 时，AER 分布参数 `a=CV²−1/mean` 趋向固定值；归一化库存与需求的分布因此近似保留原来的形状。这解释了为什么单纯放大均值可能只阻碍逐整数格点 DP，而不能阻碍合理的近似方法。

## 公平口径与可复现设置

比较 BSP、CBS、age-discount、BSP-low-EW 四种固定策略。后者沿用本仓库明确标注的混合 FIFO/LIFO 文献公式适配。所有可调数量参数均以需求均值归一化；BSP/CBS 的目标库存上限和 CBS 的单次订货 cap 参数覆盖完整实际可行范围 `[0,C]`，没有把 CBS 人为限制在小订货范围。Age-discount 从拟合 CBS 的嵌入点出发。

每个策略每个场景使用同一训练 tape、两次不同种子的相同数值优化器，每次最多 512 次目标评测。选择 age-discount 或 BSP-low-EW 只看独立验证均值。随后使用另一组新的诊断留出路径计算最终比较。各策略实际优化调用次数和参数全部保留。

- 训练：8 条路径，burn-in 200，计分 512，seed 1801001。
- 结构选择验证：32 条路径，burn-in 500，计分 1000，seed 1802001。
- 当前诊断留出：64 条路径，burn-in 500，计分 3000，seed 1804001。
- 主实验最终测试 seed 17094001 未被本程序生成或访问。

最初一次探索的 CBS cap 参数范围较窄，结果完整保留在 `initial_range_screen/`；发现参数触边后，统一扩展到完整物理范围，重新运行全部 16 个场景并使用新的诊断留出 seed。没有选择性丢弃场景，也没有按当前主实验最终测试调整生成器。本轮仍属于探索性诊断，下一轮若采用该 family 应重新冻结方法并生成新的最终测试。

大均值下，cap 的分布卷积使用 FFT 加速，需求分布和 quantile 定义没有改变。四个主场景以及两个放大场景（包括最宽尾的 `mean=40,CV=2,f=0.5`）与原始直接卷积给出的整数 cap 一致；见 `cap_validation.json`。所有 quantile 两侧 CDF 值保存在 `complexity.json`。

## 下一步应检验的实际问题

把 `m=7/8, mean=4` 的八格作为一个完整问题族，继续给予 Baek 相同分布信息、可用 Python 工具和设计时间，并加入其粗粒度 DP 或其他自选近似。同时保留 BSP-low-EW 与 age-discount 为强经典对照。只有真正跑完同等条件的 Baek 与 AIPS，才能判断多轮结构搜索和 optimizer 是否还有超出这些简单对照的收益。若希望明显大于几个百分点的结构性收益，单纯改变规模目前没有足够证据。
